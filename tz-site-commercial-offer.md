## 6. Калькулятор выгоды

Калькулятор должен считать 3 типа выгоды.

### 6.1. Штат против аутсорсинга

Формула:

```
стоимость штата = оклад gross x 1,302 + накладные расходы
выгода = стоимость штата за период - стоимость услуги за период
```

Поля:

- выбираемая услуга;
- роль, которую заменяет услуга;
- оклад gross;
- накладные расходы;
- период: месяц, квартал, 6 месяцев, год;
- стоимость услуги.

### 6.2. Снижение ожидаемых потерь

Формула:

```
ожидаемая потеря = вероятность события x ущерб
эффект = ожидаемая потеря до работы - ожидаемая потеря после работы
```

Поля:

- вероятность риска до работы;
- вероятность риска после работы;
- размер возможного ущерба.

### 6.3. Общая выгода

Формула:

```
общая выгода = экономия на штате + снижение ожидаемых потерь
ROI = общая выгода / стоимость услуги
```

Важно: расчет должен быть помечен как предварительный и не должен обещать гарантированный финансовый результат.

## 9. Ограничения

Нельзя писать:

- гарантируем одобрение кредита;
- гарантируем снижение риска;
- спасем бизнес;
- 100% результат;
- точная выгода составит.

Нужно писать:

- расчет предварительный;
- эффект зависит от исходных данных и внедрения решений;
- точные выводы возможны после анализа документов;
- услуга не является аудиторским заключением или публичной офертой.
